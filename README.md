# E-Catalog Viewer

A simple, responsive e-catalog viewer built with vanilla HTML, CSS, and JavaScript.

## 🌐 Live Demo

Visit the live: [https://dayang.onrender.com](https://dayang.onrender.com)

## Features

- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **SEO Support** - Favicon, Meta data, OpenGraph
- **Multiple Navigation Methods**:
  - Arrow buttons
  - Thumbnail strip
  - Keyboard shortcuts (arrow keys, Home, End)
  - Touch swipe gestures
  - Mouse drag support
- **Smooth Animations** - Elegant page transitions and hover effects
- **Visual Indicators** - Current page display and active thumbnail highlighting
- **Error Handling** - Graceful fallback for missing images
- **No Dependencies** - Pure vanilla JavaScript implementation

## Quick Start

1. Add your catalog images as `Page_001.png`, `Page_002.png`, etc.
2. Open `index.html` in a web browser
3. Navigate using arrows, thumbnails, or keyboard shortcuts
4. You can adjust the design and size up to your needs

## File Structure

```
/
├── index.html          # Single entry file
├── Page_001.png        # Catalog pages
├── Page_002.png
└── ...
```

## Keyboard Shortcuts

- **← / →** or **↑ / ↓**: Previous/Next page
- **Home**: First page
- **End**: Last page

The viewer automatically adapts to touch devices with swipe support.
